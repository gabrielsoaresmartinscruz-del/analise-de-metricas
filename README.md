# Miniguia de Estudo: Análise de Métricas em Campanhas de Tráfego Pago

## Resumo Estruturado

### O que são métricas de marketing digital?

Métricas são indicadores utilizados para medir o desempenho de campanhas publicitárias e auxiliar na tomada de decisões.

### Por que analisar métricas?

A análise permite identificar oportunidades de melhoria, reduzir desperdícios de orçamento e aumentar a lucratividade das campanhas.

### Quais métricas são mais importantes?

* CTR
* CPC
* CPM
* CPL
* CPA
* ROAS

### Principais aprendizados

* CTR alto não garante vendas.
* Métricas devem ser analisadas em conjunto.
* O objetivo final não é gerar cliques, mas resultados.
* Campanhas lucrativas nem sempre possuem os melhores indicadores isolados.

# Glossário

### CTR (Click Through Rate)

Taxa de cliques em relação às impressões do anúncio.

### CPC (Cost Per Click)

Valor pago por cada clique recebido.

### CPM (Cost Per Mille)

Custo para cada mil impressões do anúncio.

### CPL (Cost Per Lead)

Custo para gerar um lead.

### CPA (Cost Per Acquisition)

Custo para adquirir um cliente.

### ROAS (Return on Ad Spend)

Retorno obtido sobre o investimento em anúncios.

### Conversão

Ação desejada realizada pelo usuário, como compra ou cadastro.

### Funil de Vendas

Jornada percorrida pelo cliente até a compra.
