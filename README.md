# analise-de-metricas
O marketing digital gera milhares de dados diariamente. Métricas como CTR, CPC, CPM, CPA e ROAS são fundamentais para avaliar o desempenho de campanhas publicitárias.  Este estudo foi desenvolvido para compreender melhor como interpretar essas métricas e utilizá-las na tomada de decisões estratégicas.
